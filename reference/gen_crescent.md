# Generate Crescent

This function generates a dataset representing a structure with a
Crescent pattern.

## Usage

``` r
gen_crescent(n = 500)
```

## Arguments

- n:

  A numeric value (default: 500) representing the sample size.

## Value

A data containing a Crescent structure.

## Examples

``` r
set.seed(20240412)
crescent <- gen_crescent(n = 500)
#> ✔ Data generation completed successfully!!!
```
