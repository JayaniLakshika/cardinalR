# Package index

## Data

The example data sets.

- [`mobiusgau`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau.md)
  : Mobius clust dataset with a noise dimension
- [`mobiusgau_tsne1`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_tsne1.md)
  : tSNE embedding for mobiusgau dataset which with noise dimensions
  tSNE parameters set to perplexity: 15.
- [`mobiusgau_tsne2`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_tsne2.md)
  : tSNE embedding for mobiusgau dataset which with noise dimensions
  tSNE parameters set to perplexity: 30.
- [`mobiusgau_tsne3`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_tsne3.md)
  : tSNE embedding for mobiusgau dataset which with noise dimensions
  tSNE parameters set to perplexity: 5.
- [`mobiusgau_umap1`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_umap1.md)
  : UMAP embedding for mobiusgau dataset which with noise dimensions
  UMAP parameters set to n-neigbors: 15 and min-dist: 0.1.
- [`mobiusgau_umap2`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_umap2.md)
  : UMAP embedding for mobiusgau dataset which with noise dimensions
  UMAP parameters set to n-neigbors: 30 and min-dist: 0.08.
- [`mobiusgau_umap3`](https://jayanilakshika.github.io/cardinalR/reference/mobiusgau_umap3.md)
  : UMAP embedding for mobiusgau dataset which with noise dimensions
  UMAP parameters set to n-neigbors: 5 and min-dist: 0.9.
- [`three_clust_01`](https://jayanilakshika.github.io/cardinalR/reference/three_clust_01.md)

- [`three_clust_02`](https://jayanilakshika.github.io/cardinalR/reference/three_clust_02.md)
