# Generate Helical Hyper Spiral

This function generates a dataset representing a structure with a
helical hyper spiral.

## Usage

``` r
gen_helicalspiral(n = 500)
```

## Arguments

- n:

  A numeric value (default: 500) representing the sample size.

## Value

A data containing a helical hyper spiral.

## Examples

``` r
set.seed(20240412)
helicalspiral <- gen_helicalspiral(n = 500)
```
